This repository contains a Deep Learning project for classifying skin lesions into 7 different categories using the **HAM10000 Dataset**. To maximize predictive performance, we trained multiple State-of-the-Art (SOTA) CNN architectures and implemented an **automated Top-3 Weighted Ensemble** pipeline.

---

## 📊 Dataset

The **HAM10000** (Human Against Machine with 10000 training images) dataset consists of dermatoscopic images of different pigmented skin lesions. 
The 7 target classes are:

1. Actinic keratoses and intraepithelial carcinoma / Bowen's disease (**akiec**)
2. basal cell carcinoma (**bcc**)
3. benign keratosis-like lesions (solar lentigines / seborrheic keratoses and lichen planus-like keratoses, **bkl**)
4. dermatofibroma (**df**)
5. melanoma (**mel**)
6. melanocytic nevi (**nv**)
7. vascular lesions (angiomas, angiokeratomas, pyogenic granulomas and hemorrhage, **vasc**)

---

## 🚀 Models & Architecture

We utilized **Transfer Learning** with the following pre-trained backbones:

- **ConvNeXt-Tiny**
- **DenseNet121**
- **ResNet50**
- **Xception**

### Custom Enhancements

- **Focal Loss**: Addressed extreme class imbalance in the dataset.
- **Data Augmentation**: Cutout, Random Flips, Rotations, and Color Jittering.
- **Mixed Precision Training**: Optimized for modern GPU acceleration.

### Individual Model Performance (Validation Set)

| Model             | Accuracy | Balanced Accuracy | Macro F1 | Weighted F1 |
|:----------------- |:--------:|:-----------------:|:--------:|:-----------:|
| **ConvNeXt-Tiny** | 0.90     | 0.8585            | 0.85     | 0.90        |
| **DenseNet121**   | 0.89     | 0.8471            | 0.85     | 0.90        |
| **Xception**      | 0.88     | 0.8190            | 0.83     | 0.88        |
| **ResNet50**      | 0.87     | 0.8356            | 0.83     | 0.87        |

## 🏆 Ensemble Strategy & Results

Instead of relying on a single model, we implemented a robust **Weighted Averaging Ensemble**:

1. The script evaluates all saved `.keras` models on a hold-out validation set.
2. It automatically ranks them and selects the **Top 3 Models** based on *Balanced Accuracy*.
3. Predictions on the test set are generated by combining the probabilities of the Top 3 models, weighted by their validation scores.

### Final Ensemble Performance

- **Accuracy**: ~`92%`
- **F1-Score**: ~`91%`

*(Detailed Confusion Matrix and ROC-AUC curves are generated automatically inside the `model_metrics/` directory after running the script).*

## ⚙️ Installation & Setup

1. **Clone the repository:**
   
   ```bash
   git clone https://github.com/your-username/skin-cancer-classification.git
   cd skin-cancer-classification
   ```

2. **Set up Virtual Environment and Install Dependencies:**
   
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install --upgrade pip
   pip install -r requirements.txt
   ```

3. **Dataset Preparation:**
   Ensure the HAM10000 dataset is placed in the `./dataset` folder. The structure should look like:
   
   ```text
   dataset/
   ├── HAM10000_metadata.csv
   ├── HAM10000_images_part_1/
   └── HAM10000_images_part_2/
   ```

## 💻 Usage

To run the automated ensemble pipeline, simply execute:

```bash
python3 ensemble.py
```

**Optional Arguments:**
If your dataset or model weights are stored elsewhere, you can specify their paths:

```bash
python3 ensemble.py --data_path /path/to/dataset --weights_dir /path/to/weights
```
